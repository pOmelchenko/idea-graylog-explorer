# Security policy

Report vulnerabilities privately to **p.Omelchenko@gmail.com**. Do not open a public issue containing exploit details, credentials or production logs.

Include the affected plugin version, IDE build, a minimal reproduction and the expected security boundary. Use synthetic values. If a token was exposed, revoke it in Graylog rather than sending it with the report.

Security fixes target the latest public development release, currently the 0.12.x line. There is no support commitment for older local prototype versions.
